# Sounds supplied by the app's owner

A file here replaces the synthesised sound of the same game and event: `supplied/<game>/<event>.mp3` (events: start, step, tick, land,
reveal, launch, cashout, special, win, bigwin, lose). `build.py` decodes it with ffmpeg, trims it, makes it as loud as every other sound
and puts it in the game's pack. (A looping background track is different: use `music.py`.)

| File | Where it comes from |
|---|---|
| `aviator/special.mp3` | The 1.9 s sound the owner sent for Aviator (file name `aviator_background_music.mp3`, sent in the chat on 2026-11-19). The owner first called it the take-off sound, then corrected that: it is the **crash** sound. It plays when the plane crashes and never before: the server keeps the crash secret until it happens, and the app plays nothing that could warn a player. Its container tags show it was cut out of a video. **The owner is responsible for having the rights to use it.** |
| `wingo/countdown.flac` | The last-5-seconds countdown sound of Win Go: six dings, one for each of 5, 4, 3, 2, 1 and 0 seconds left, 5.7 s in all. Cut from the audio of a screen recording of **BG678's Win Go** (the owner's file `wingo_.mp4`, sent in the chat on 2026-11-19; only this audio is kept, not the video). The app plays it from 5.1 s before a round ends, in Win Go **and in K3, 5D and Trx Win** (the owner asked for the same sound there; `build.py` shares this one file, see `SUPPLIED_SHARED`). It is another company's app: **the owner is responsible for having the rights to use it.** |
| `sevenupdown/reveal.mp3` | The dice-roll sound of Seven Up Down: the rattle of the dice, 1.1 s (the owner's file `ludo_.mp3`, sent in the chat on 2026-11-21; its container tags show it was cut out of a video). It plays while the dice roll: from the moment betting closes, for the 2 s until the result, for everyone watching with or without a bet (`revealForAll` in `src/sound/games.ts`). The roll is longer than the file, so `build.py` repeats it once, cross-fading the repeat into it, to cover the 2 s (`SUPPLIED_COVER`); the landing sound after it is still the pack's own. **The owner is responsible for having the rights to use it.** |
| `ui/tap.mp3` | The touch sound: a bright "ting" at about 2.2 kHz, 0.13 s with its ring. It plays when a button, tab, tile, row or switch of the menus is tapped (Home, the game lists and a game tile, Settings, Profile, Wallet, VIP, Earn, the bottom tabs, the dialogs ...) and on the interface buttons of the game screens (Back, Deposit, Rules, History, the sound switch). The owner's file `jackpot_sound.mp3`, sent in the chat on 2026-11-20: 0.93 s, of which only 0.14 s is sound (0.36 s of silence before it), very quiet (peak -21 dBFS); its container tags show it was cut out of a video. It is an interface sound: `build.py` brings it up to a normal level, trims it and writes `assets/sounds/ui/tap.mp3`, `src/sound/ui.ts` plays it. **The owner is responsible for having the rights to use it.** |
| `ui/chip_bet.mp3` | The chip sound ("tunke"): 0.35 s, a soft low thump and then the hit, the same length as the chip's flight onto the table. It plays when a chip goes onto a bet: the seven chip table games (Seven Up Down, Dragon Tiger, Andar Bahar, Teen Patti, Jhandi Munda, Roulette, Baccarat) and Blackjack. The owner's file `cgannn_original_wala_.mp3`, sent in the chat on 2026-11-20. It replaces the table games' own bet sounds. It is an interface sound: `build.py` writes it to `assets/sounds/ui/chip_bet.mp3` (levelled by the whole sound, see `UI_LEVEL_BY_WHOLE`) and `src/sound/ui.ts` plays it. **The owner is responsible for having the rights to use it.** |
| `ui/popup_close.mp3` | The popup-closing sound: a 0.15 s pop (the file is 1.75 s, the sound sits at 0.65 s) that plays when the cross of any popup is tapped (in the games: rules, history, the win cards, GAME INFO; and the popups added from the admin panel, the deposit offers, VIP, Profile, Withdraw). The owner's file `popup_cutting.mp3`, sent in the chat on 2026-11-20; its container tags show it was cut out of a video. It is an interface sound, not a game's: `build.py` writes it to `assets/sounds/ui/popup_close.mp3` and `src/sound/ui.ts` plays it. The touch sound that was to follow is `ui/tap.mp3`. **The owner is responsible for having the rights to use it.** |
| `ui/bet_now.flac`, `ui/bet_stop.flac` | The voice calls of Seven Up Down: "Bet... now..." (1.0 s) when a new round opens for betting and "Bet... stop..." (1.1 s) when betting closes, each spoken together with its banner (blue "Start Betting", red "Stop Betting", the same banners as Dragon Tiger's). The owner asked for them on 2026-11-21, and then (same day) for the voice to be clearer and drawn out, "Bet... Now...". **Not a recording of anyone and not from another app:** `scripts/sounds/voice.py` made them with Kokoro, an open-weight text-to-speech model (Apache-2.0 licence, trained only on permissive / non-copyrighted audio, run offline) and its female voice "af_bella", so they can be used freely. The words are written as Kokoro phonemes at speed 0.72 with a pause between them, and the wording and voice were picked by trying the permissively licensed voices and checking with an offline speech recognizer that the finished clips are heard as "bet now" and "bet stop" (the first version, Piper's "mike" voice, lost the "b" of "bet" in a speech recognizer's ears and was too quick). They are interface sounds: `build.py` writes `assets/sounds/ui/bet_now.mp3` and `bet_stop.mp3` (1.25x louder than the other interface sounds, see `UI_GAIN`, so they carry over the game's music) and `src/sound/ui.ts` plays them (`playBetCall`), only while the app is in front and the sound switch is on. |
